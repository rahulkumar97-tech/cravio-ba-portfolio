# Cravio – Wireframes

This folder contains the wireframes created for the **Cravio – Online Food Delivery Platform**.

The wireframes provide a visual representation of the proposed user experience and help translate functional requirements into an initial interface structure.

---

## Customer Journey Wireframe

The Customer Journey Wireframe represents the primary flow a customer may follow while using the Cravio platform.

### Main Flow

```text
Login / Registration
        ↓
Browse Restaurants
        ↓
Search / Filter Food
        ↓
View Food Item
        ↓
Add to Cart
        ↓
Checkout
        ↓
Select Payment Method
        ↓
Place Order
        ↓
Track Delivery
        ↓
Order Delivered
```

### Purpose

The wireframe helps to:

* Visualize the customer journey.
* Identify major screens and interactions.
* Validate the flow before development.
* Connect user experience with documented requirements.
* Provide a reference for future UI development.

---

## Tool Used

The wireframe was created as part of the Cravio BA portfolio project and is maintained as a supporting design artifact.

```text
Requirements
```
