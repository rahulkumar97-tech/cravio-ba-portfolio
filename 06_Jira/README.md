# Cravio – Jira & Agile Project Management

This section documents how the **Cravio – Online Food Delivery Platform** project was structured and managed using Jira.

Jira was used to organize requirements into Epics, User Stories, and Tasks and to understand the Agile/Scrum workflow.

---

## Jira Project

**Project Name:** Cravio – Online Food Delivery Platform
**Project Key:** CRAVIO
**Project Type:** Team-managed Scrum Project

---

## Epic Structure

The project was divided into six major Epics:

| # | Epic                  | Focus Area                                              |
| - | --------------------- | ------------------------------------------------------- |
| 1 | Customer Management   | Customer account and authentication features            |
| 2 | Restaurant Management | Restaurant and menu-related functionality               |
| 3 | Food Ordering         | Restaurant browsing, cart, checkout, and ordering       |
| 4 | Payment Management    | Payment processing, confirmation, failures, and refunds |
| 5 | Delivery Management   | Delivery assignment, tracking, and completion           |
| 6 | Admin Management      | Platform administration and monitoring                  |

---

## Jira Work Items

The backlog was organized into:

* **6 Epics**
* **40 User Stories**
* **13 Tasks**

User Stories were created with:

* User Story statement
* Acceptance Criteria
* Relevant Epic

Tasks were created with:

* Task objective
* Related Story
* Task details
* Relevant Epic

## Acceptance Criteria

Acceptance Criteria were documented within the Story descriptions to define the conditions that must be satisfied for a User Story to be considered complete.

Example:

```text id="8d7qk2"
User Story:
As a customer, I want to register an account so that I can use the Cravio platform.

Acceptance Criteria:
- Customer can enter required registration details.
- System validates the submitted information.
- Valid details create a customer account.
- Invalid details display an appropriate validation message.
```
